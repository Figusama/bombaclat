# Состояние и план (обновлено 18.10.2026 ~03:30, дедлайн 18.10 12:00)

## Как продолжить (команды)
```bash
cd ~/personal/datahon2
# окружение: используется ~/personal/datathon/.venv (python3.14, mlx-vlm, torch) — в нём всё установлено.
# (.venv в datahon2 недоустановлен из-за медленной сети; можно добить: .venv/bin/pip install -r requirements.txt)
PY=~/personal/datathon/.venv/bin/python
set -a; source .env; set +a; export HF_HUB_OFFLINE=1

# полный прогон датасета (факты кешируются в data/cache/facts, точечные проверки — *_checks_v5.json):
$PY tools/run_eval.py --tag r3            # отчёт: reports/eval_r3.md, лог: reports/eval_r3.log
# отладка одного видео (факты, шкала людей, проверки, нарушения):
$PY tools/debug_video.py X-20
# сервер (UI http://localhost:8000, ключ в .env):
nohup $PY -m uvicorn app.main:app --host 0.0.0.0 --port 8000 > data/server.log 2>&1 &
# публичный URL для жюри:
cloudflared tunnel --url http://localhost:8000     # установлен через brew
# сквозной тест API:
tools/smoke_api.sh
```

## Что сделано
- Модель выбрана бенчмарком (reports/bench_summary.md): Qwen3.5-9B-4bit (79%) > Qwen3-VL-8B (62%) > Molmo2-8B (59%); все три скачаны в ~/.cache/huggingface.
- Пайплайн: кадры 2 fps → RT-DETR люди (маска «внутри кассы» по верхней кромке стола + зонам) → grounding ROI (стол, сейф, ноутбук, дверь, машинка) → факты по сегментам (prompt v5, адаптивно 4–8 кадров/сегмент, ≤16 сегментов) → точечные проверки кропами (уход: сейф/ноутбук/стол; сейф открыт; документ клиента; ручной пересчёт; сумка→сейф) → правила (pipeline/rules.py) → нарушения с кадрами (рамка зоны + кроп) и НПА (catalog/violations.yaml, 25 типов).
- API по ТЗ (POST /api/v1/analyze, GET /api/v1/jobs/{id}, X-API-Key), UI на русском, очередь из одного воркера, кеши.
- Документы: README.md, docs/api.md, Dockerfile (вариант для Linux/CUDA, не тестировался).
